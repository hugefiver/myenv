** 核心概念

- *Buffer*: Emacs 中的文件/内容容器，一个 buffer 对应一个文件或临时内容
- *Window*: 显示 buffer 的视口，一个 frame 里可以有多个 window
- *Frame*: 操作系统窗口
- *Minibuffer*: 底部的命令输入区域
- *Mode*: 每个 buffer 有一个主模式 (major-mode) 和多个辅助模式 (minor-mode)

* 🎨 自定义

** 更换主题

在 =init.el= 中找到 ~(load-theme 'doom-gruvbox t)~ ，替换为其他主题：

#+begin_src emacs-lisp
;; 暖色系
(load-theme 'doom-gruvbox t)          ; 当前使用
(load-theme 'doom-molokai t)          ; Monokai 风格
(load-theme 'doom-palenight t)        ; 淡紫夜色
(load-theme 'doom-tokyo-night t)      ; 东京之夜

;; 冷色系
(load-theme 'doom-one t)              ; Atom One Dark
(load-theme 'doom-nord t)             ; Nord 极光
(load-theme 'doom-dracula t)          ; Dracula

;; 亮色
(load-theme 'doom-one-light t)
(load-theme 'doom-gruvbox-light t)
#+end_src

按 =C-c i= 快速打开 init.el 编辑。

** 字体大小

在 =init.el= 中修改 =:height 125= (单位: 1/10 pt，125 = 12.5pt)。

* 💡 小贴士

1. *不记得快捷键？* 按任意前缀键后等待 0.5 秒，=which-key= 会弹出提示
2. *想执行某个命令？* =M-x= 然后输入关键词模糊搜索
3. *Evil 模式不习惯？* =C-c e= 随时切回 Emacs 键位
4. *文件找不到？* =M-s f= 在项目中模糊查找文件名
5. *代码找不到？* =M-s r= 在项目中全文搜索（需要 =ripgrep=）
6. *窗口乱了？* =C-c <left>= 用 winner-mode 撤销窗口变化
7. *想看撤销历史？* =C-x u= 打开 undo-tree 可视化界面
